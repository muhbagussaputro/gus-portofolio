# Gus Portofolio

Project portfolio berbasis Next.js.

## Development

```bash
npm install
npm run dev
```

Buka `http://localhost:3000`.

## Available scripts

```bash
npm run dev
npm run build
npm run start
npm run lint
```

## Stack utama

- Next.js
- React
- TypeScript
- Tailwind CSS

## Deployment note

README ini sengaja tidak memakai instruksi deployment spesifik platform. Konfigurasi deployment dan environment production dikelola terpisah dari repository.
